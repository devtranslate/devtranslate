✏️ Devtranslate
Repositório oficial do projeto Devtranslate, uma iniciativa open source que visa facilitar o acesso a conteúdos técnicos de tecnologia traduzidos para o português, promovendo inclusão e aprendizado na comunidade de TI.

📌 Visão Geral
O Devtranslate é uma plataforma colaborativa que organiza e disponibiliza traduções de documentos técnicos da área de tecnologia. Nosso objetivo é centralizar e facilitar o acesso a materiais traduzidos, permitindo que mais pessoas possam aprender e se desenvolver na área, independentemente do domínio do idioma original.

🌐 Funcionalidades
Catálogo de Traduções: Acesse uma variedade de documentos técnicos traduzidos, organizados por categorias e tags.

Contribuição Comunitária: Participe ativamente do projeto, contribuindo com novas traduções ou revisando conteúdos existentes.

Interface Intuitiva: Navegue facilmente pelo site e encontre rapidamente os materiais de seu interesse.

API Pública: Utilize nossa API para integrar as traduções em outras plataformas ou aplicações.

🛠️ Tecnologias Utilizadas
Frontend: Desenvolvido com TypeScript e React, utilizando Webpack para empacotamento e Storybook para documentação de componentes.

Backend: API construída com C# e ASP.NET Core, oferecendo endpoints RESTful para acesso aos dados.

UI Components: Biblioteca de componentes reutilizáveis em construção, visando padronização e reutilização de elementos visuais.

English Version

✏️ Devtranslate
Official repository for the Devtranslate project — an open source initiative aimed at making technical content in the technology field more accessible by providing community-driven translations into Portuguese.

📌 Overview
Devtranslate is a collaborative platform that organizes and publishes translated technical documents in the software development field. Our goal is to centralize access to high-quality translated materials, enabling more people to learn and grow in tech, regardless of their English proficiency.

🌐 Features
Translation Catalog: Access a wide range of translated technical documents, organized by category and tags.

Community Contribution: Help grow the platform by translating new content or reviewing existing translations.

User-Friendly Interface: Easily browse and find materials relevant to your learning.

Public API: Use our API to integrate translations into other platforms or applications.

🛠️ Tech Stack
Frontend: Built with TypeScript and React, using Webpack for bundling and Storybook for UI documentation.

Backend: RESTful API powered by C# and ASP.NET Core.

UI Components: A reusable component library is in progress to ensure consistency and scalability.

🚀 How to Contribute
Fork this repository.

Create a new branch: git checkout -b my-contribution.

Make your changes and commit: git commit -m 'My contribution'.

Push to your fork: git push origin my-contribution.

Open a Pull Request describing your changes.

Please read our Contributing Guide for more details.
